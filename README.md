# Student Results Platform

A simple, fast web app to manage student results, generate graphs, and scrape BISE Lahore results using a requests-based scraper (no Selenium).

## Features

- Upload and manage CSV results
- Live graphs and statistics
- PDF report generation
- High-performance results scraper with retries, random delays, and browser-like headers
- Supports large batches (1000+ roll numbers)

## Tech Stack

- Python + Flask
- HTML/CSS/JS (Chart.js)
- Requests + BeautifulSoup + ddddocr
- ReportLab + Matplotlib

## Quick Start

### 1) Setup

```bash
# Activate your venv (example for Windows Git Bash)
source scrap_web/Scripts/activate

# Install dependencies
pip install -r requirements.txt
```

### 2) Run the app

```bash
python app.py
```

Open in browser:

```
http://127.0.0.1:5000
```

### 3) Run the scraper (CLI)

```bash
python scraper.py
```

## Configuration

- Set max parallel workers for scraping:

```bash
# Windows CMD
set SCRAPER_MAX_WORKERS=10

# PowerShell
$env:SCRAPER_MAX_WORKERS="10"
```

## Render Deployment (Queue Mode)

For Render, scraping should run in a separate worker using Redis + RQ.

1. Create a Redis instance on Render.
2. Set `REDIS_URL` for both web and worker services.
3. Web service start command:

```bash
python app.py
```

4. Worker service start command:

```bash
python worker.py
```

## CSV Format

Required columns:

```
Roll_Number,Name,Father_Name,Total_Marks
```

Optional columns (generated by scraper):

```
Status,Subject_Pass
```

## API Endpoints

- `GET /api/results` - All results
- `POST /api/upload-csv` - Upload CSV/Excel
- `POST /api/clear-data` - Clear results
- `GET /api/download-sample` - Sample CSV
- `GET /api/graph-data` - Stats for graphs
- `POST /api/scrape` - Start background scraper
- `GET /api/scrape-status` - Scraper progress
- `GET /api/download-pdf` - PDF report

## Troubleshooting

- If charts are empty, confirm data in Student_Results.csv.
- If PDF fails, install reportlab and matplotlib from requirements.
- Captcha OCR can fail. The scraper retries automatically.
